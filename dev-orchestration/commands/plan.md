Use the planning-orchestrator agent to create a complete, audit-approved implementation plan.

The orchestrator will automatically:
1. Create the implementation plan from your PRD, AppGraph, and architecture specs
2. Audit the plan for completeness and alignment
3. Refine the plan if any issues are found
4. Provide you with a production-ready implementation plan

Please analyze the feature requirements and create a comprehensive implementation plan that is ready for development.
