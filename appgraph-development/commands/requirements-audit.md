description: Audit a PRD against the AppGraph to identify gaps, conflicts, and risks
---

Use the requirements-auditor agent to audit the PRD against the existing AppGraph.

The auditor will:
1. Extract semantic elements from the PRD (entities, operations, interfaces, constraints)
2. Analyze AppGraph context and identify related nodes and patterns
3. Detect integration gaps (missing integrations with existing components)
4. Detect specification gaps (missing details needed for implementation)
5. Detect pattern conflicts (violations of established patterns)
6. Assess risks (integration, security, impact)
7. Analyze completeness (CRUD operations, states, edge cases)
8. Generate a comprehensive audit report with prioritized recommendations

Please perform a thorough requirements audit and generate a detailed report.
