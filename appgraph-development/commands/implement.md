---
description: Implement a task with automated testing, auditing, and fixing using the task orchestrator
---

Use the task-orchestrator agent to implement a complete task with automated quality assurance.

The orchestrator will automatically:
1. Implement the task code and tests (via task-implementer)
2. Execute tests and collect metrics (via test-executor)
3. Audit the implementation for quality and compliance (via code-auditor)
4. Fix any issues found if necessary (via code-fixer)
5. Provide you with production-ready, audit-approved code

Please specify which Phase and Task you want to implement (e.g., "Phase 1, Task 1.1") and the orchestrator will handle the complete implementation workflow.
