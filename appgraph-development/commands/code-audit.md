description: Audit implemented code for compliance, quality, and alignment
---

Use the code-auditor agent to audit the implementation.

The auditor will:
1. Verify alignment with the implementation plan
2. Assess code quality, patterns, and tech stack compliance
3. Evaluate test coverage and quality
4. Detect unrequired functionality and scope drift
5. Identify gaps, issues, and improvements needed

Please specify which task to audit and the auditor will generate a detailed compliance and quality audit report.
