---
description: Audit implementation plans against AppGraph and architecture for conflicts, gaps, and risks
---

Use the implementation-plan-auditor agent to audit the implementation plans.

The auditor will:
1. Validate all node/edge references against the current AppGraph
2. Detect conflicts (non-existent nodes, attribute mismatches, pattern violations, schema incompatibilities)
3. Identify gaps (missing integration specs, cascade effects, dependencies)
4. Assess risks (integration, regression, impact scope, consistency)
5. Calculate coverage scores (how well decisions are grounded in AppGraph)
6. Simulate impact on the existing AppGraph
7. Check alignment with architecture specifications and patterns

This audit is particularly useful when:
- Implementation plans were generated by external tools
- Plans may reference an older version of the AppGraph
- Plans were created without full knowledge of the existing system
- You need to validate plans before coding begins

Please perform a comprehensive audit of the implementation plans and generate a detailed audit report with actionable recommendations.
