Use the plan-auditor agent to audit the implementation plan.

The auditor will:
1. Verify all PRD requirements are covered
2. Validate AppGraph alignment (all nodes/edges in impact subgraphs)
3. Check tech stack alignment with architecture specs
4. Assess task quality and success criteria
5. Identify gaps, drifts, and improvements needed

Please perform a comprehensive audit of the implementation plan and generate a detailed audit report.
