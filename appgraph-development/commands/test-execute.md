Use the test-executor agent to run tests and collect detailed statistics.

The executor will:
1. Run all unit tests for the implemented task
2. Collect test results, coverage metrics, and performance data
3. Analyze test failures and identify patterns
4. Generate a comprehensive test report with statistics

Please specify which task's tests to execute and the executor will provide detailed test results and coverage analysis.
