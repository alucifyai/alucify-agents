description: Refine an implementation plan based on audit findings
---

Use the plan-refiner agent to refine the implementation plan.

The refiner will:
1. Detect project mode (greenfield vs brownfield)
2. Read the audit report and identify all issues (critical, major, minor)
3. Address all critical and major issues
4. Add missing coverage for PRD requirements and AppGraph nodes
5. Remove out-of-scope tasks
6. Improve task quality, success criteria, and alignment
7. Produce a complete, standalone refined version

**For greenfield projects**, the refiner will additionally:
- Restructure Phase 1 to ensure it produces a deployable component
- Improve phase structure for incremental deployment
- Replace codebase references with architecture document references
- Add parallelization annotations and cross-codebase coordination

Please refine the implementation plan to address all audit findings and produce an improved version.
