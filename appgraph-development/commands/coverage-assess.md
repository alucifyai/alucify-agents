---
description: Assess the lineage coverage of an implementation plan against the AppGraph
---

Use the coverage-assessor agent to assess the implementation plan's lineage coverage.

The assessor will:
1. Extract all decisions from the implementation plan
2. Validate each decision against AppGraph nodes and edges
3. Calculate coverage scores (fully covered, partially covered, not covered)
4. Identify gaps and ungrounded decisions
5. Generate a comprehensive coverage assessment report

Please perform a thorough coverage assessment and generate a detailed report with recommendations.
